# 잔해 구역

브라우저에서 바로 하는 3D 탈출 슈팅 게임입니다. 장비를 챙겨 출격하고, 전리품을 모아 살아서 탈출하면 됩니다.

- 바로 하기: https://ctple.github.io/scrap_yard/
- 혼자 하기, 파티를 꾸려 협동하기 모두 됩니다.
- 설치 없이 PC와 모바일 브라우저에서 돌아갑니다.

## 맵

| 맵 | 특징 |
| --- | --- |
| 지하 연구 시설 | 지하 3개 층이 겹쳐 쌓인 실내 교전 |
| 장거리 협곡 | 절벽 사이 1200m 협곡, 거점과 벙커를 지나는 원거리 교전 |

## 조작법 (PC)

| 키 | 동작 |
| --- | --- |
| WASD / Shift | 이동 / 달리기 |
| 마우스 왼쪽 / 오른쪽 | 발사 / 조준 |
| Space | 점프 |
| R | 재장전 |
| C (누르는 동안) / Z | 앉기 / 엎드리기 |
| Q / E | 몸 기울이기 |
| F / Tab / H | 상호작용 / 가방 / 치료 |
| G / V / B / T | 수류탄 / 방어구 수리 / 특수 탄창 / 레이저, 라이트 |
| 1 2 3, 휠 | 무기 교체 |
| Esc | 일시정지 |

오른쪽 위 "전체 화면" 버튼으로 주소창과 탭 없이 게임 화면만 볼 수 있습니다.

모바일은 화면 왼쪽을 끌어 이동하고, 오른쪽을 끌어 시점을 돌립니다.

## 구성

- `index.html`: 게임 전체 (Three.js, 파일 하나)
- `server/`: 협동전 멀티플레이 서버 (Node.js, Render에서 실행)
  - 접속 현황: https://ctple.onrender.com/stats
  - 접속 기록: `logs` 브랜치의 `logs/날짜.txt`

## 버전 규칙

`v첫째.둘째.셋째.넷째` 형식입니다. 각 자리는 20까지 쓰고, 넘어가면 뒤에 알파벳을 붙입니다 (예: v1.2.20a).

- 첫째: 새 엔진, 큰 구조 변경, 도구 추가, 시즌 변경
- 둘째: 새 모드나 새 맵
- 셋째: 화면 구성, 멀티 구조 변경, 동작 추가, 맵 구조 변경
- 넷째: 조작, 수치 조정, 버그 수정
